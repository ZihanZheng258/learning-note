方法借用（Method Borrowing）是 JavaScript 中一个非常灵活且强大的技巧，它利用了 JavaScript 函数的两个核心特性：

1. **函数是对象（Function is an object）：** 函数可以作为值传递。
    
2. **`this` 关键字的可变性：** 函数可以在执行时动态指定其内部 `this` 的指向。
    

简单来说，**方法借用就是将一个对象 A 上的方法，拿来给另一个对象 B 使用。**

## 核心原理：`call`, `apply`, 和 `bind`

方法借用的实现依赖于所有 JavaScript 函数都拥有的三个内置方法：

### 1. `call()` 和 `apply()`：临时借用并执行

`call` 和 `apply` 可以立即执行函数，并允许你**显式指定函数内部的 `this` 值**。

- **语法:** `Function.call(thisArg, arg1, arg2, ...)`
    
- **语法:** `Function.apply(thisArg, [argsArray])`
    

**示例：借用数组方法**

假设我们有一个类似数组的对象 `arguments`（或 NodeList），==它有索引和 `length` 属性，但没有 `Array.prototype.forEach` 方法。==


```js
// 假设这是某个函数内部的 arguments 对象
const args = { 
    0: 'apple', 
    1: 'banana', 
    length: 2 
};

// 目标：我们想让 args 对象使用 Array.prototype.forEach
Array.prototype.forEach.call(args, function(item) {
    console.log(item); 
    // 当 forEach 在 args 上执行时，内部的 this 被设为 args
    // forEach 就可以像处理真正的数组一样处理 args
});

// 输出:
// apple
// banana
```

在这个例子中：

- 我们借用了 `Array.prototype.forEach` 这个方法。
    
- 通过 `.call(args, ...)`，==我们将 `forEach` 内部的 `this` 临时指向了 `args` 对象，从而使得 `forEach` 能够遍历 `args` 的元素。==
    

### 2. `bind()`：永久创建借用的函数

`bind` 方法会创建一个**新函数**，这个新函数在未来无论何时被调用，其 `this` 值都会被永久地绑定到你指定的目标对象。

- **语法:** `Function.bind(thisArg, arg1, arg2, ...)`
    

**示例：借用并永久绑定日志方法**

假设我们有一个全局的 `log` 对象，==但我们想让一个模块直接使用它，而不需要每次都写 `log.print()`。==


```js
const logger = {
    prefix: '[APP]',
    logMessage: function(message) {
        console.log(`${this.prefix} ${message}`);
    }
};

const moduleA = {
    // 借用 logger.logMessage 并将 this 永久绑定到 logger
    emitLog: logger.logMessage.bind(logger) 
};

moduleA.emitLog("初始化完成"); 
// 输出: [APP] 初始化完成
```

## 为什么要使用方法借用？（应用场景）

方法借用是一种优雅且高效的解决特定编程模式的方式：

1. **处理类数组对象 (Array-like Objects)：** 这是最常见的用途。许多 DOM 集合（如 `document.querySelectorAll` 返回的 NodeList）或函数的 `arguments` 对象都是类数组对象。它们没有完整的数组方法，通过方法借用可以获得强大的数组操作能力。
    
    - **经典示例：** 将类数组对象转换为真正的数组：
        
        ```js
        const realArray = Array.prototype.slice.call(arguments);
        // 或者使用更现代的语法：
        const realArrayModern = Array.from(arguments);
        ```
        
2. **代码复用：** 当两个对象具有相似的结构，但其中一个缺少另一个已有的方法时，可以直接借用方法来避免重复编写代码。
    
3. **函数柯里化和偏函数应用：** 利用 `bind` 来预设函数的 `this` 和部分参数。
    
4. **模块化和工具函数：** 抽取通用方法并绑定到特定对象上作为工具函数。
