为 `fetch` 构建表单参数主要有两种常见的方式，取决于你想发送的数据格式：

1. 发送传统的 **`application/x-www-form-urlencoded`** 格式数据（传统网页表单格式）。
    
2. 发送支持文件上传的 **`multipart/form-data`** 格式数据。
    

这两种情况都推荐使用内置的 **`URLSearchParams`** 和 **`FormData`** 对象来简化构建过程。

## 1. 传统表单数据：`application/x-www-form-urlencoded`

这种格式通常用于简单的表单提交，数据是以 `key=value&key=value` 的形式发送的。

### 使用 `URLSearchParams`

`URLSearchParams` 对象是构建这种格式数据的最简单、最安全的方式，它会自动进行 URL 编码。

```js
// 步骤 1: 准备数据
const dataToSend = {
    username: '张三',
    password: 'mypassword123',
    remember_me: 'on'
};

// 步骤 2: 使用 URLSearchParams 转换数据
const formBody = new URLSearchParams(dataToSend);

// 步骤 3: 构建 fetch 请求
fetch('https://api.example.com/login', {
    method: 'POST',
    // 关键：设置 Content-Type 头部
    headers: {
        'Content-Type': 'application/x-www-form-urlencoded' 
    },
    // 将 URLSearchParams 对象用作 body
    body: formBody 
})
.then(response => response.json())
.then(result => console.log('登录结果:', result))
.catch(error => console.error('错误:', error));
```

## 2. 复杂表单数据：`multipart/form-data`（包含文件）

这种格式用于上传文件，因为它能够将不同类型的数据（文本、文件等）分隔成不同的部分发送。

### 使用 `FormData`

**`FormData`** 对象专门用于构建这种格式的请求体，并且它是**唯一**能轻松处理文件上传的方法。

```js
// 假设这是 HTML <input type="file"> 元素
const fileInput = document.getElementById('myFileInput'); 
const selectedFile = fileInput.files[0]; 

// 步骤 1: 创建 FormData 实例
const formData = new FormData();

// 步骤 2: 使用 append() 方法添加字段
formData.append('username', '李四');
formData.append('age', 25);
// 添加文件：第一个参数是字段名，第二个参数是 File 对象
formData.append('profile_picture', selectedFile); 

// 步骤 3: 构建 fetch 请求
fetch('https://api.example.com/upload', {
    method: 'POST',
    // 关键：不要手动设置 Content-Type 头部！
    // 浏览器会自动设置正确的 'Content-Type: multipart/form-data; boundary=...'
    // 如果你手动设置，它将无法正确生成 boundary。
    // headers: { 'Content-Type': 'multipart/form-data' }, // ❌ 不要这样写
    
    body: formData // 直接将 FormData 对象用作 body
})
.then(response => response.json())
.then(result => console.log('上传结果:', result))
.catch(error => console.error('错误:', error));
```

### 总结要点

| 格式                                      | 使用对象                  | 场景               | `Content-Type` 头部                                 |
| --------------------------------------- | --------------------- | ---------------- | ------------------------------------------------- |
| **`application/x-www-form-urlencoded`** | **`URLSearchParams`** | 简单、纯文本的表单提交。     | **必须设置** 为 `'application/x-www-form-urlencoded'`。 |
| **`multipart/form-data`**               | **`FormData`**        | 包含**文件上传**的表单提交。 | **不要手动设置**，浏览器会自动处理。                              |
